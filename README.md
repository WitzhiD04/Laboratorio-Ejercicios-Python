## Contenido de los notebooks

| Notebook | Tema |
|---|---|
| 01_Ejercicios_Basicos.ipynb | Operaciones y manipulacion de cadenas de texto |
| 02_Tuplas_Python.ipynb | Creacion, indexacion y ordenamiento de tuplas |
| 03_Listas_Python.ipynb | Creacion, indexacion y concatenacion de listas |
| 04_Conjuntos_Python.ipynb | Conjuntos (sets), union y subconjuntos |
| 05_Diccionarios_Python.ipynb | Diccionarios clave-valor, keys() y values() |
| 06_Condiciones_Python.ipynb | Estructuras condicionales if, elif y else |
| 07_Bucles_Python.ipynb | Bucles for y while |
| 08_Funciones_Python.ipynb | Definicion de funciones y comportamiento del operador + |
| 09_Clases_Python.ipynb | Programacion orientada a objetos: clases, atributos y metodos |
| 10_Bonos_Python.ipynb | Ejercicios de refuerzo que integran los temas anteriores |

Cada notebook incluye un membrete de identificacion al inicio y una seccion de conclusiones al final.

La carpeta `scripts/` contiene versiones en `.py` de los ejercicios usadas como borrador de trabajo y con los códigos de ejemplo de los cuadernos del taller,antes de pasar el contenido final a los notebooks con el fin de dejar los cuadernos más simples.
